# Cửu Vực combat sandbox (Godot 4.2+)

Open `game/project.godot` with Godot 4.2 or newer, then press F6/F5 to run.

Controls: A/D or arrows to move, Space/W/Up to jump, J to attack, K/Shift to dodge, R to restart.

First playable scope: player movement, jump, melee attacks, stamina-based invulnerable dodge, simple pursuing enemy, HP HUD, win/loss and restart. All visuals are placeholders generated at runtime.

Not yet included: authored art, animation, hitstop, attack telegraphs, combo chains, audio, inventory, Mạch Ấn, loot, checkpoints or narrative.

Validation: static code review only. Godot executable was not available in the authoring environment; run the project in Godot to confirm engine compatibility and feel.
