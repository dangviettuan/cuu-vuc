# ADR-0005 — Prose chapter numbering

Status: **Accepted**

## Decision

Prose story chapters (`story/`) are numbered independently of game chapters (Narrative Bible: Prologue, Chapter I–XII).

Every prose draft must state, in its header, which game chapter or chapters it covers.

## Reason

Prose pacing and game pacing differ. One game chapter may span several prose chapters, and the game's Prologue is already prose "Chương 1". Forcing the two to match would distort one or the other.

## Example

`story/drafts/chapter-01-cai-gieng-can.md` — prose Chương 1, covering game **Prologue — An Mộc**.
