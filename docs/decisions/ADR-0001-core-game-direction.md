# ADR-0001 — Core Game Direction

Status: Accepted

## Decision

Cửu Vực is an offline single-player 2D side-scrolling action RPG with handcrafted story stages.

It includes class building, attributes, skill progression, equipment upgrades, loot and boss-focused combat.

It is not planned as an MMO, multiplayer game, roguelike or open world.

## Reason

The desired experience focuses on authored narrative, character development, boss design, meaningful build progression and consequential player choice.
