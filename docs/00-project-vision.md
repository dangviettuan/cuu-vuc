# Project Vision v0.1

## Elevator pitch

**Cửu Vực** is an offline single-player 2D side-scrolling action RPG set in a world divided by nine spiritual veins. The player journeys through handcrafted regions, fights bosses, collects items and Mạch Ấn, upgrades equipment, develops skills and attributes, and chooses a class-based combat path.

Its defining feature is not merely progression. The player gradually gains enough power to affect the fate of civilization while discovering that every major solution carries a moral cost.

## Core experience

**Hub → authored stage → exploration/combat → loot → checkpoint → mini-boss/boss → consequence → return/advance → upgrade/build → story branch.**

## Scope

- Mode: offline single-player
- Camera: 2D side-scrolling
- Structure: handcrafted chapters/stages; selective revisits
- Combat: real-time action, boss pattern learning, Souls-lite pressure without copying Souls structure
- Character progression: level, attributes, skill tree, equipment, class identity
- Loot: meaningful passive effects, not only numerical upgrades
- Boss progression: boss rewards include Mạch Ấn that can alter builds
- Narrative: branching consequences, no visible morality meter
- Endings: seven sin-aligned endings plus an eighth ending, Nhân Gian
- Open world: no
- Roguelike/procedural world: no
- Multiplayer: no

## Narrative pillar

The central question is:

> **Chỉ vì ta có thể quyết định, liệu ta có quyền quyết định thay tất cả mọi người?**

The protagonist begins with confidence in a clear boundary between right and wrong. Across the game that certainty is broken by people making understandable but harmful decisions under impossible circumstances.

The game must not tell the player which philosophy is objectively correct.
