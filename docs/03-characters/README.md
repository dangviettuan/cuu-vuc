# Character Bible — Next Design Target

Status: **Not yet canonized**, except where explicitly noted below.

## Canonized protagonist identity rule

The protagonist does **not** have a fixed canonical personal name.

At the start of a new game, the player enters the protagonist's name in a text field. Narrative, UI, dialogue and save data must resolve that value dynamically.

The protagonist is still an authored character with a fixed narrative foundation: childhood, family relationships, core personality, worldview, emotional wounds and major character arc are designed by the game. Player agency changes decisions, relationships, build and endings rather than replacing the protagonist with a blank avatar.

In design documents, use `PLAYER_NAME` or **Protagonist** as the neutral reference instead of inventing a canonical name.
